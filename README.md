# Grade B Streak

A streak-based daily planner for the RBI Grade B exam, built around EduTap's 9-Month Day-Wise Study Plan.

- **Hours drive the streak.** Five one-hour blocks a day. Any logged hour keeps the streak; all five make a goal day.
- **Two shifts a day.** Today shows the EduTap chapter for each shift by its plan day number. Tick a chapter when you work on it, mark Done when it is finished.
- **Sundays are revision.** Weeks 30 to 39 follow EduTap's revision blocks.
- **To-do list**, hours per week and per month, and a 16-week heatmap.

Progress is stored in the browser you open the app in. Use the backup text under Settings to move it between devices.

## Run it

Open `index.html` in a browser, or serve it from GitHub Pages: Settings → Pages → Deploy from branch `main`, folder `/ (root)`.
Then add the Pages URL to your phone's home screen.

Chapter list and day numbers follow EduTap's plan. The plan PDF itself is not included.
